# 本轮修复清单

## 平板无法发送到电脑

原因：

- 电脑端服务本身可用，但 Windows 防火墙阻止了局域网入站访问。
- 默认端口可能被占用或保留。
- 防火墙程序规则绑定旧 exe 路径。

修复：

- 增加多个接收端口 fallback。
- 增强手动连接端口尝试逻辑。
- 增加 Windows 防火墙检测和一键修复。
- 一键修复支持当前运行路径、Debug 路径、Release 路径。
- 清理当前 exe 路径上已有的阻止规则。

## 复制 Release 到新目录后不能收

原因：

- `D:\NearSend\nearsend.exe` 是新的绝对路径。
- Windows 防火墙可能已有该路径的阻止规则。
- 阻止规则优先级高于允许规则。

修复：

- 一键修复会按当前运行 exe 路径清理旧入站规则。
- 清理后重新创建允许入站规则。

## 防火墙设置页误报

原因：

- Windows 防火墙规则查询不够稳定。
- `netsh` 和 `Get-NetFirewallRule` 返回格式不同。
- 实际已经收到入站请求，但 UI 仍按检测脚本结果显示未放行。

修复：

- 如果已经收到平板入站请求，UI 以真实连通为准。
- 实际可达后隐藏原始 `detect` 诊断内容。

## 多图片传输红屏

错误：

```text
_ShadProgressState is a SingleTickerProviderStateMixin but multiple tickers were created.
```

原因：

- 多个传输任务同时刷新进度时，进度组件重复创建 ticker。

修复：

- 替换为稳定的普通进度条实现，避免多个 ticker 冲突。

## 手动连接后没有打开会话

原因：

- 手动连接只完成设备发现或注册，没有正确激活会话窗口。

修复：

- 手动连接成功后创建或更新会话，并切换到聊天界面。

## 文字消息不能选择复制

原因：

- 消息气泡使用普通 `Text`。

修复：

- 改为 `SelectableText`。
- 桌面端支持鼠标拖选复制。
- Android 平板端支持长按选择复制。
